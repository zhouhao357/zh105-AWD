方法 说明 是否带请求体
GET 查询数据，参数拼在 URL 查询串上（?limit=5） 否
POST 新增数据，数据放在请求体 Body 里 是
PUT 整体替换某个资源 是
PATCH 局部修改某个资源 是
DELETE 删除资源 可选
HEAD / OPTIONS 只取响应头 / 询问服务器支持哪些方法 否
常见错误与处理方式
网络错误 域名不存在 / 断网 → fetch 直接 reject，用 try-catch 捕获
HTTP 错误状态 404、500 等 → fetch 不会自动报错，必须自己判断 res.ok
跨域被拦 服务器未返回 Access-Control-Allow-Origin → 浏览器控制台报错
请求超时 用 AbortController 主动中断
