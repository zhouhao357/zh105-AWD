图一：销售额与增长率（柱状图 + 折线图 双 Y 轴）

数据含义：某电商平台近 6 个月 GMV（柱）与同比增长率（线），可直观看到“量涨利薄”的趋势。

图二：品类销售占比（环形饼图 + 玫瑰图）

数据含义：各一级品类销售额占比，点击扇区可高亮，配合右侧百分比标签查看明细。
① 引入本地 ECharts <script src="cdn/echarts.min.js"></script>， 文件已下载到项目内的 cdn 目录，不依赖外网； 若联网也可以换成 https://cdn.jsdelivr.net/npm/echarts@5/dist/echarts.min.js。
② 三步走：初始化 → 写 option → setOption echarts.init(dom) 得到实例，setOption(option) 绘制； 窗口尺寸变化时记得调用 chart.resize()。
③ 常用配置 tooltip 提示框、legend 图例、grid 留白、 xAxis / yAxis 坐标轴、series 数据系列（type 决定图形）。
④ 联动与事件 chart.on('click', ...) 监听点击； setOption(option, true) 表示全量覆盖更新， notMerge: true 可清除旧系列后再画。

配置项 作用 本例取值
tooltip.trigger 提示框触发方式 axis（按坐标轴联动）
yAxis[].type / yAxisIndex 坐标轴类型与归属系列 value + value，第二个用不同 yAxisIndex
series[].type 图形类型 bar / line / pie / roseType
radius 饼图半径，支持百分比数组 ['45%', '68%']（环形）
label.formatter 标签文本格式化 '{b}: {d}%'
chart.resize() 容器尺寸变化后重绘 绑定 window resize 事件
