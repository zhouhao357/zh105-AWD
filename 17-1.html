规则 正确 ✔ 错误 ✘
键必须用双引号 {"name": "周浩"} {name: "周浩"}、{'name': ...}
字符串值必须用双引号 {"city": "长春"} {"city": '长春'}
不能写函数、undefined 只放 数字 / 字符串 / 布尔 / null / 数组 / 对象 {"fn": function(){}}（会被丢弃）
不能有注释、末尾不能有多余逗号 {"a": 1, "b": 2} {"a": 1,}、{/*xx*/}
字符串 ↔ 对象 互转 JSON.parse(jsonStr)、JSON.stringify(obj) 直接把字符串当对象用（jsonStr.name 是 undefined）
